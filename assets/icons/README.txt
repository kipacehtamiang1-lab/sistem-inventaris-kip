Folder ini disediakan sesuai struktur proyek, tapi seluruh ikon pada tampilan
saat ini memakai inline SVG langsung di HTML (bukan file terpisah) supaya
warna ikon otomatis mengikuti tema (currentColor) tanpa perlu banyak file.

Kalau nanti butuh ikon custom (misalnya logo tambahan atau ikon khusus di
luar kumpulan yang sudah dipakai), taruh file .svg atau .png di sini dan
rujuk lewat <img src="../assets/icons/nama-file.svg">.
